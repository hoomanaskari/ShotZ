# ShotZ 0.1.2

Fixes for the editor's Background panel, and a privacy and security tidy-up.

- Sliders in the editor now follow the pointer. Padding, Corners, Angle, Opacity, Corner radius and Redaction strength used to jump to the end and stick there.
- Position in the Background panel now moves the image, with any aspect. When there is no room to move it, the grid is greyed out and says why.
- Saving a Background preset works: the name field is ready for typing, and Save waits until you have typed a name.
- Your captures, documents and history are now stored so that only your user account can read them. Existing files are tightened the first time 0.1.2 starts; files you save or export are not affected.
- ShotZ's log entries no longer show file names or paths.
- The app no longer contains file paths from the computer it was built on.
- Developer test switches are ignored by the released app.
- Settings ▸ Advanced has a new Acknowledgements row with the licences for ShotZ and the open-source software it includes.
