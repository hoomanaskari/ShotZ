# ShotZ 0.1.1

A small follow-up to the first release.

- Clicking a switch, button or other control no longer leaves a blue focus ring around it. The ring now appears only when you move between controls with the keyboard (Tab).
- The Screen Recording step now explains what to do if ShotZ appears twice in System Settings after updating from an earlier build.
- Settings ▸ Advanced shows the new version, 0.1.1.
- Internal: release checks for the signing team, and safer tests.
